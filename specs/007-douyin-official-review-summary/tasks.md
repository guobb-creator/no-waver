## 2. 实施约束

- 优先使用抖音官方开放平台 API。
- 不使用第三方抖音数据 API。
- 高德交通摘要保持不变。
- 小红书第三方方案暂不实现。
- 抖音 API Key、token、secret 只在服务端使用。
- 每个目的地最多展示 3 条相关高互动视频。
- 摘要、浏览器预览、App 跳转必须绑定同一视频标识。
- 评论能力作为可选增强，取决于官方权限。
- 抖音失败不阻塞高德交通摘要。
- 日常模块不受影响。
